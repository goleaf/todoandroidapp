# Documentation Instructions for Agents

- Place all new Markdown documentation (other than the root `README.md`) inside this `docs/` directory or its subdirectories.
- Update existing documents in `docs/` whenever relevant features change so that guidance stays current.
- Maintain clear run instructions for both the Flutter client and the Dart server when features are added that affect them.
- Preserve the use of explanatory comments in all Dart and server-side code that you modify or add.
